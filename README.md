## Professional Experience

### Leaning Technologies — Software Engineering Intern

Contributed to the development of [CheerpJ](https://cheerpj.com/),
a WebAssembly-based Java runtime that enables Java applications
to run directly in web browsers.

- Contributed to OpenJDK 21 and 25 runtime compatibility and support.
- Investigated and resolved JVM runtime issues involving MethodHandles,
  bytecode execution, stack walking, and memory operations.
- Improved compatibility with Java applications and libraries,
  including SwingSet3, FlatLaf, and Elemental.
- Debugged low-level issues involving filesystem operations,
  class loading, and runtime execution.
- Developed minimal reproductions and tests to investigate runtime
  behaviour and validate fixes.

**Technologies:** C++, Java, JavaScript, WebAssembly, OpenJDK,
JVM, Linux, Git.
